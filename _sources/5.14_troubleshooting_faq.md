# Troubleshooting & FAQ

**Python not found in MATLAB**  
- `pe = pyenv` then `pyenv("C:\Path\to\python.exe")`. Ensure required packages are installed.

**TensorFlow GPU not used**  
- `py.importlib.import_module('tensorflow')` inside MATLAB; verify CUDA/cuDNN match the TF build.

**CV fold errors with tiny batches**  
- Enable *Small‑batch safeguards* in CV settings; inspect the CV‑cycle log.

**MEX build for F‑score**  
- Set up a supported compiler in MATLAB (`mex -setup`).

**Viewer performance with large NIfTI**  
- Downsample for exploration; export at full resolution for figures.
