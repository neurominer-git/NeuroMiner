# Glossary (NM 1.4 additions)

**Aggregated back‑projection** — single composite map \(w_{\mathrm{agg}}=\sum_c w_c v_c\) from latent‑space models.  
**Component‑wise back‑projection** — factor‑resolved maps \(w^{(\mathrm{backproj})}_c=w_c v_c\) shown for discovered components.  
**Selective inference** — hierarchical testing where feature‑level inference is conditioned on component‑level discovery.  
**Hungarian assignment** — maximum‑weight matching used to align components across CV1 folds.  
**\(L_p\) share** — modality‑level or component×modality contribution based on \(p\)-norm magnitudes of back‑projected maps.  
**Selection under the null** — mirroring the component selection rule in permuted data (e.g., rank‑matched top‑K, threshold‑matched).
