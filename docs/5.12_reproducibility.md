# Reproducibility checklist (NM 1.4)

## Seeds & randomness
- Fix seeds for CV split generation and model training when available.
- For SA/BO, fix seeds for the initial design and temperature schedule.

## CV generation log
- NM writes a **CV cycle generation log** per run (fold indices, batch allocations, reassignments). Save it with your results so you can rerun the same splits.

## Python/MATLAB bridge
- Record `pyenv` (executable & version) and export `pip freeze` for the linked environment.

## Hardware
- Log CPU/GPU info and CUDA/cuDNN versions if using TensorFlow.

## Minimal report template
- Data version & preprocessing hash  
- CV framework & folds/permutations  
- Search strategy (grid/SA/BO) & budget  
- Selected metrics & regularization  
- External validation / ComBat application policy
