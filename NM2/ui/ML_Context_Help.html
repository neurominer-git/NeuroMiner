Machine learning: settings and scientific meaning

Context help for prediction criteria, learners, model optimization, and selection.

Optimization criterion

The selected performance criterion determines how candidate models are compared during hyperparameter optimization. The criterion is evaluated on cross-validation predictions; its direction of improvement (higher or lower) follows the chosen measure.

Model performance criterion

Select the performance measure used to compare candidate models in the optimization procedure. The optimization direction follows the measure: for example, prediction errors are minimized, while accuracy measures are maximized. Expected calibration error requires probability estimates.

Learner selection and fixed settings

Choose the learning algorithm and its fixed settings. Different algorithms expose different solvers, kernels and parameters; changing the algorithm replaces dependent defaults and parameter ranges.

Automatic hyperplane weighting

Enable automatic weighting of cases or outcome classes for learners that support it. Weighting changes the contribution of observations to the fitting objective, including when the training classes have unequal sizes.

Kernel type

Select the kernel function used to compare observations in kernel-based learners. Linear kernels operate without a nonlinear kernel transformation; polynomial and radial-basis kernels introduce additional parameters defining their shape.

Learning algorithm

Select the learning algorithm used to train the predictive model. Available fixed settings and hyperparameter ranges change with this selection; previously entered dependent settings are replaced by those of the selected algorithm.

GLMNET family

Output probability scores

LIBLINEAR tolerance

Model optimization

Choose how candidate hyperparameter configurations are explored: direct grid enumeration, simulated annealing or Bayesian optimization. Search controls affect exploration and computational cost, not the outer cross-validation test partition.

Initial temperature

Initial temperature controls how readily simulated annealing accepts candidate moves with worse optimization scores. This helps the search move beyond a locally best configuration.

Maximum initial jump

Limits how far the search can move through the parameter grid at the start of simulated annealing.

Cooling factor alpha

Temperature multiplier applied during cooling. It controls how rapidly the simulated annealing search becomes less exploratory.

Random jump probability

Probability that a simulated annealing proposal is chosen randomly rather than as a local step on the parameter grid.

Maximum iterations

Maximum number of simulated annealing iterations, limiting the number of search proposals.

Iterations until reheating

Number of iterations between temperature-reheating operations in simulated annealing.

Reheating factor

Temperature multiplier used when the simulated annealing schedule reheats.

Bayesian optimization maximum iterations

Maximum number of Bayesian optimization iterations after setting up the search.

Maximum iterations without improvement

Number of consecutive iterations without improvement allowed before Bayesian optimization stops.

Seed iterations

Number of initial configurations evaluated to initialize the Bayesian optimization surrogate.

Gaussian-process kernel

Choose the covariance kernel of the Gaussian-process surrogate used to model performance over the hyperparameter search space.

Bayesian optimization acquisition

Choose the acquisition function used to propose new configurations. The available strategies include lower confidence bound and expected improvement.

LCB kappa

Set the exploration weight in lower-confidence-bound acquisition, balancing predicted performance against uncertainty in the surrogate.

EI jitter

Set the jitter parameter used by expected-improvement acquisition when evaluating candidate configurations.

Hyperparameter optimization method

Choose the method used to search candidate hyperparameter configurations: exhaustive grid search, simulated annealing, or Bayesian optimization. The search method changes which candidates are evaluated and in what order.

Model-selection strategy

Choose how the cross-validated performance of candidate hyperparameter configurations is used to select a model or ensemble. Percentile settings determine which configurations enter an ensemble.

Cross-parameter model selection

Select either a single best-performing configuration or an ensemble of configurations based on their cross-validated performance.

Fixed ensemble percentile

Set the performance percentile used to determine which configurations enter a fixed-threshold ensemble.

Percentile search vector

Specify candidate performance percentile thresholds when the ensemble threshold is optimized rather than fixed.

Prediction post-processing

Configure optional changes to predicted scores or targets after fitting. The effect depends on whether the analysis predicts categorical classes or a continuous outcome.

Detrend targets / optimize decision threshold

Enable the task-dependent post-processing stage. In regression it applies output detrending; in classification it optimizes the decision threshold on the relevant training-side predictions.
