Workflow and processing stages

Preprocessing workflow

NeuroMiner executes ordered transformations of predictor or outcome data. The stage determines when settings are estimated, which cases contribute to them and how the transformed representation enters later analysis.

Global label and target processing

Global options affect labels or regression targets rather than predictor columns. For a three-class classification, group-processing mode determines whether preprocessing is fitted for class comparisons or all classes together; it does not change the original labels. Missing training labels can be propagated in a CV-bound step. Scaling or a power transform of a continuous outcome is configured separately for regression.

Subject-specific preprocessing

Operations here act on each subject’s signal before CV partitioning. Image-preserving transformations can be composed in sequence before an operation that extracts image-derived features.

CV-bound preprocessing

Methods in this stage estimate parameters from the corresponding training fold and apply the fitted transformation to its held-out cases. The order of operations determines which feature representation each method receives.

External application (OOCV)

Preprocessing fitted during model training is reused when applying the model to an independent cohort. The fitted operations appear as read-only; available application-specific settings are shown separately.

Global handling of missing labels

The global missing-label operation currently leaves missing labels unchanged. Label propagation, when selected, is represented as a CV-bound preprocessing step fitted on training cases.

Outcome transformation

Regression targets can be scaled and optionally raised to a power before fitting. The legacy power transform is y_transformed = y^p (for example, 2^2 = 4), not exp(y). Both operations change the units of predictions; evaluate reported errors and any back-transformed predictions on the intended target scale. Power transforms of negative values require a mathematically valid exponent.

OOCV label imputation

Apply available label-imputation logic to external cases using the fully preprocessed training representation associated with the trained analysis.

Combining subject-specific operations

Gaussian smoothing and spatial wavelet reconstruction retain the spatial feature axis, so their outputs can feed JuSpace or atlas-based regional extraction. JuSpace, ROI means and spatial KL graph extraction replace image-space features with derived features; this limits which imaging operations can follow them.

Wavelet reconstruction versus wavelet variance removal

Subject-specific spatial wavelet reconstruction separates signal across spatial scales while retaining voxel or vertex identity. CV-bound wavelet variance-component removal instead attenuates components associated with a nuisance target. Their parameters and outputs are not interchangeable.

Network preprocessing

Graph construction defines edges or network representations. Graph sparsity can remove edges, and graph metrics summarize the retained structure. The meaning of those summaries therefore depends on the preceding graph construction and thresholding.

Ranking and dimension extraction

Ranking and selecting are separate steps: a ranking method might assign weights 0.9, 0.5 and 0.1 to three features; the immediately following ranking action can retain the top two or apply the weights without removing columns. A dimensionality-reduction step instead fits new components, which an extraction step can truncate to candidate component counts. Their order is essential: the action consumes the preceding fitted scores or projection.

Imputation

Choose how missing predictor values are estimated within each training fold. Median or single-value strategies use simple summaries; group means use outcome-related groups; k-nearest-neighbour (kNN) methods borrow information from similar observed cases; hybrid methods distinguish categorical from continuous features. For example, a missing age can be replaced from similar training cases rather than set to zero. The fitted rule is then applied to held-out cases; imputation must not learn from test-fold outcomes.

Imputation method

Choose the treatment of missing predictor entries. median uses a median-based replacement; mean uses feature-wise group means; downshift replaces values according to the inherited downshift rule. cityblock (sum of absolute differences), euclidean (straight-line distance), seuclidean (scale-adjusted Euclidean), cosine (vector-direction similarity), hamming (fraction of mismatching categories) and jaccard (mismatching nonzero categories) provide distance choices for k-nearest-neighbour imputation. SeqkNN denotes sequential kNN imputation, which updates estimates through an ordered neighbour procedure. hybrid uses separate distance rules for nominal and continuous features. For instance, a missing value in a continuous feature can be estimated from the k most similar training cases. These methods have different assumptions; no option makes missingness automatically ignorable.

Features to impute

Use all available features, or restrict imputation to a user-defined feature subspace.

Feature subspace mask

Logical feature mask encoded as 0/1 values. Its length must equal the number of features when that context is known.

Number of nearest neighbours

Number of neighbours used by distance-based and SeqkNN imputation; ignored by methods that do not use neighbours.

Hybrid method for nominal features

For categorical variables, Hamming distance counts the proportion of unequal entries (for example, male/female versus male/male); Jaccard distance emphasizes agreement and disagreement among nonzero/present categories rather than joint zeros. Use Hamming when every category match matters; consider Jaccard for sparse binary indicators where shared absence should not dominate similarity.

Hybrid method for ordinal / continuous features

For quantitative features choose cityblock (absolute differences), Euclidean (squared-difference distance), standardized Euclidean (adjusts for differing spreads), cosine (directional similarity) or SeqkNN (sequential nearest-neighbour estimation). Age measured in years can otherwise dominate a variable measured between 0 and 1; review feature scaling when selecting a distance metric.

Maximum unique values for nominal imputation

Hybrid imputation treats a feature as nominal when it has no more than this number of distinct observed values; features with more distinct values use the continuous/ordinal distance rule. At a cutoff of 3, a three-category response is nominal, whereas a feature with four distinct values is not. A small cutoff can misclassify coarse ordinal scales; inspect the data before setting it.

Label imputation

Assign missing outcome labels to training observations with the selected propagation method. The label-propagation model is estimated inside the training fold; this is distinct from global handling of missing labels.

Label propagation method

Label propagation estimates missing outcome labels for training observations from cases whose labels are known. none leaves labels missing; learner uses the configured prediction model; kNN options predict from nearby labelled training cases according to a selected distance metric. The neighbour count is configured separately. Because labels may be used during preprocessing, the propagation model must be fitted inside each training fold, never using held-out labels. Imputed labels are estimates, not verified clinical diagnoses.

Number of nearest neighbours

Number of neighbours used by KNN-based label-propagation methods.

Gaussian smoothing

Apply a Gaussian spatial filter to each subject’s image-space representation. The full spatial grid is retained. Consequently, smoothing can precede JuSpace or atlas-based feature extraction: those subsequent operations act on the smoothed signal, not on the original map.

Gaussian filter width [mm]

FWHM means full width at half maximum, a conventional measure of Gaussian smoothing width in millimetres. A larger FWHM averages signal across a broader spatial neighbourhood (for example, 8 mm blurs more than 4 mm), reducing local detail while potentially improving signal-to-noise. Entering multiple widths makes them candidates for optimization; interpret them relative to image resolution and anatomy.

Wavelet spatial reconstruction

A spatial wavelet separates an image into slowly varying patterns (low spatial frequency) and fine local variation or edges (high spatial frequency) at several scales. Choose which parts to reconstruct: an approximation retains broad patterns, denoising keeps selected details, and detail-only outputs emphasize local change. Volumes use 3-D wavelet kernels; cortical surfaces use graph heat-kernel wavelets following the surface mesh. Outputs retain the original voxel/vertex locations, so subsequent spatial steps can still use them.

Wavelet kernel

B3-spline wavelets provide smoother, overlapping scale decompositions; Haar uses step-like differences that are more sensitive to sharp local transitions. Both operate on volumetric image grids. Cortical surfaces use heat-kernel graph wavelets so neighbourhoods follow connected vertices on the folded surface rather than straight-line 3-D voxel distances. Kernel choice alters the spatial patterns retained at each level.

Boundary handling

For volumetric wavelets, mirror padding reflects values at the image boundary, whereas zero padding treats values beyond the boundary as zero. This setting does not apply to cortical heat-wavelets.

Decomposition level(s)

A level identifies the spatial scale of a wavelet representation. Lower levels emphasize finer detail; successive levels describe broader patterns. Selecting levels 1 and 3 evaluates or reconstructs those scales rather than a single fixed smoothing width. On surfaces, increasing heat-wavelet levels similarly broadens the neighbourhood along the cortical mesh; exact spatial reach depends on geometry and the kernel.

Reconstruction mode

Choose which wavelet signal is returned. approximation gives broad low-frequency structure; denoised combines that structure with details that survive thresholding; selected details sums chosen signed high-frequency bands; detail bands keeps separate signed residuals at each level. detail magnitude uses absolute residuals, and detail energy uses squared residuals: both discard the positive/negative sign, so they should not be interpreted as signed changes. Use approximation for broad patterns and signed details when direction matters.

Apply wavelet reconstruction to external weighting image

A ranking image supplied from outside the pipeline may be in the original image representation while subject images have been wavelet-reconstructed. Enable this option to transform the weighting map consistently before the subsequent ranking step. Otherwise weights refer to the original spatial pattern. This matters especially for detail-only reconstruction, where a weight on a smooth image may not represent the retained spatial signal.

Detail levels to reconstruct

Specify the high-frequency wavelet levels used by selected-details reconstruction. Level 1 contains relatively fine spatial changes; adding levels 2 and 3 includes progressively broader detail. The reconstruction branches include only bands available at their current level, so choosing 1–3 yields D1, then D1 + D2, then D1 + D2 + D3. Unlike magnitude or energy, selected details preserve the sign of residuals.

Detail thresholding

Choose whether detail coefficients are left unchanged, softly shrunk toward zero, or hard-thresholded to zero. Thresholding is applied when the denoised reconstruction uses detail coefficients.

Threshold multiplier

The threshold is expressed as a multiplier of a robust noise estimate from each subject's wavelet-detail coefficients. Increasing the multiplier removes more small coefficients and generally produces a smoother, less detailed reconstruction; decreasing it keeps more detail and potentially more noise. Compare candidate values with image resolution and the expected spatial scale of the effect.

Subject batch size

Set how many subjects are processed in one batch of spatial wavelet operations. This affects working memory and processing overhead, not the meaning of the wavelet coefficients.

JuSpace neuromap correlations

Quantify spatial correspondence between individual neuroimaging maps and selected molecular or cellular reference maps. Each selected reference map yields correlation-derived features, replacing the original image-space representation. This feature-extraction step can follow an image-preserving operation such as Gaussian smoothing or spatial wavelet reconstruction.

Detected JuSpace directory

Displays the location of the JuSpace resources used to prepare the selected reference maps.

Atlas image path(s)

An atlas partitions the brain into labelled regions (parcels). JuSpace first summarizes the subject map and each reference map within these parcels and then relates the regional patterns. The atlas and maps must describe corresponding anatomy and spatial geometry; an unmatched atlas can produce invalid regional comparisons even when the correlation calculation runs.

Alternative atlas name(s)

Assign optional names to the selected atlas images. These names identify the parcellation definitions in resulting analyses.

Brain maps directory

Choose the directory containing molecular or cellular reference maps. Scanning this directory supplies the list from which the maps used in the analysis are selected.

Brain-map scan status

Shows the outcome of the reference-map directory scan; it is a status display, not an analysis parameter.

Brain map selection

Select the reference brain maps to correlate with each subject’s image. Each selected map contributes its own spatial association feature; alternative names label the corresponding outputs.

Correlation type

Pearson correlation measures a linear spatial association between parcel values. Spearman correlation assesses the correspondence of their ranks and is less sensitive to the numerical spacing between values.

Adjust for spatial autocorrelation

Brain maps are spatially autocorrelated: neighbouring regions tend to have similar values even without a specific biological association. Ordinary correlations therefore overstate the amount of independent spatial evidence. Enable adjustment when interpreting correspondence between subject and reference maps; the correction accounts for spatial dependence in the module's estimation path. It does not itself establish causal or region-specific effects.

TPM image path

TPM means tissue probability map, an image estimating the probability of tissue classes such as gray matter at each location. Specify this optional spatial resource when using the JuSpace spatial-autocorrelation adjustment that relies on tissue information. It must occupy compatible anatomical space with the atlas and subject/reference maps.

JuSpace import/precomputation complete

Report whether the selected atlas and reference maps have been prepared for the JuSpace computation. Changing the resource selection requires the resulting preparation state to be updated.

ROI mean extraction

Summarize an image using mean signals in atlas-defined regions. The output is a vector of regional features instead of the voxel/vertex image. An image-preserving filter may precede regional averaging; operations requiring image-space input cannot follow regional extraction.

Atlas image path(s)

Select an atlas whose labelled regions of interest (ROIs) correspond spatially to the input image or surface. The module averages the signal within each ROI to create one predictor per region. For example, a 100-region atlas can produce a regional feature vector instead of thousands of voxel values. Incorrect atlas alignment changes the meaning of every extracted feature.

Atlas directory

Directory containing the atlas resources used by this step.

ROI atlas import complete

Indicates whether atlas preparation for this step is complete.

Imported spatial operation

A previously configured spatial operation is retained when an existing analysis is loaded. Its scientific settings come from the stored analysis; this representation is not offered as a new editable module.

Scaling

Scaling changes numerical ranges without necessarily centering observations around zero. Min–max [0,1] maps the training minimum to 0 and maximum to 1; min–max [-1,1] maps them to -1 and 1; symmetric [-1,1] divides by the largest absolute training value and preserves the original zero. For training values -2, 0, 6, symmetric scaling yields about -0.33, 0, 1, whereas min–max [0,1] yields 0, 0.25, 1. The fitted transformation is reused for held-out cases.

Scale across whole matrix

Normally each predictor column is scaled using its own training minimum/maximum or magnitude. Enable whole-matrix scaling to use one shared range across all features. For example, columns measured in millimetres and milliseconds can then have very different final ranges; use this only when their relative original magnitudes are meaningful.

Scaling range

Three options are available. Min–max [0,1] maps the observed training minimum/maximum to 0/1. Min–max [-1,1] maps them to -1/1 but may move a true zero away from zero. Symmetric [-1,1] divides by the largest absolute training value: -2, 0 and 6 become approximately -0.33, 0 and 1. Choose the zero-preserving option where zero has meaning (required for stacking); none of these guarantees held-out values stay inside the training range.

Zero-out non-finite values

When enabled, non-finite outputs of scaling are set to zero. When disabled, those values remain non-finite and can be processed by subsequent imputation steps.

Standardization

Standardization expresses features relative to a location (mean or median) and a measure of dispersion. Mean/SD z-scoring makes a value one standard deviation above the training mean approximately +1; robust options use medians or resistant spread estimates when outliers would distort the mean. The same estimates are applied to validation/test cases, and the method should match the scale and outlier structure of the predictors.

Estimator

Mean/SD standardization subtracts the training mean and divides by standard deviation; median-based standardization uses a robust center and spread (optionally IQR). Mean or L1-median centering removes a location without necessarily setting unit variance. Qn and Sn are robust scale estimators less sensitive to extreme observations than SD. Prefer robust estimators for heavy-tailed features; the appropriate choice depends on the downstream learner.

Use IQR for median standardization

IQR is the interquartile range: the 75th minus 25th percentile. Use it as the spread measure for median-centered standardization instead of the alternative default estimate. For values with a few extreme outliers, IQR changes less than standard deviation; features with negligible IQR still need valid handling of near-constant values.

Winsorization limits in SD units

Winsorization limits unusually extreme values by replacing them with boundary values rather than removing entire cases. A cutoff of 3 SD, for example, caps observations beyond the chosen limits. This reduces outlier influence but also removes real extremes; an empty setting disables winsorization. Limits are estimated from the available training partition.

Zero-out completely non-finite features

When standardization yields non-finite entries (NaN or Inf), this option converts them to zero. This can occur with missing data or degenerate feature spread. Zero then represents a processed value rather than an observed measurement; consider pruning or imputation when the distinction matters.

Source covariates

Source covariates identify the reference subgroup whose training observations determine the standardization center and spread, for example controls or a designated acquisition site. This affects which population defines a z-score. Confirm that subgroup coding and availability are appropriate within each training fold.

Destination covariates

Destination covariates identify which cases receive the fitted reference-group standardization. For example, parameters estimated in controls can be applied to patients. This choice affects the scope of the adjustment, not which cases were used to estimate it; see Source covariates for the estimation population.

Unit normalization

Rescale feature vectors to unit length under the chosen norm. This changes magnitude while retaining the feature directions defined by the selected normalization rule.

Norm

L1 normalization divides a vector by the sum of absolute feature values; L2 divides by the square root of the sum of squared values. Thus [3,4] becomes [3/7,4/7] under L1 but [0.6,0.8] under L2. Both remove overall vector magnitude and can alter relationships when absolute signal size is informative.

Zero-out non-finite values

Replace non-finite values produced by unit normalization with zero.

Discretize / symbolize

Discretization converts continuous measurements into bins; symbolization converts a signal into a sequence of discrete codes. For example, ages 18–29 and 30–39 could become two categories rather than retaining exact ages. Fewer bins simplify patterns but discard within-bin differences; these transformations are particularly relevant to algorithms that require discrete inputs.

Mode

discretize maps numbers to bins defined by the start, step and stop values (for example, 0 to 4 in steps of 1); symbolize uses a data-dependent symbolic representation controlled by the number of bins, sequence length and SD range. The first retains interval codes, the second encodes sequences of signal states. Both lose some numerical precision.

Discretization bin start

Lower starting value for the discretization bin grid.

Discretization bin step

Positive spacing between consecutive discretization bins.

Discretization bin stop

Upper stopping value for the discretization bin grid.

Symbolization minimum bins

Lower bound for candidate symbolization bin counts. For example, a minimum of 3 and maximum of 8 asks the symbolization routine to consider resolutions from three to eight categories. Smaller bins counts preserve less numerical detail but may be more stable with limited data.

Symbolization maximum bins

Upper bound for symbolization bin counts. Raising it permits finer categories, but rare bins may become sparsely populated. It must not be smaller than the minimum bin count; consider sample size when selecting a broad range.

Symbolization sequence length

Number of adjacent symbols grouped into a symbolic sequence. Longer sequences can distinguish more detailed temporal patterns but require sufficient observations to populate the resulting symbol combinations. Set it in relation to the available signal length rather than treating it as a feature count.

Symbolization STD range

STD denotes standard deviation. This parameter specifies how many standard deviations of signal variability define the symbolization range around its reference center. Larger values cover a broader value range; smaller values concentrate the binning resolution near typical observations.

Prune invalid / zero-variance features

Remove predictors that do not satisfy the selected finite-value, variance, or value-frequency criteria. Pruning changes the number of features available to downstream learners.

Prune zero-variance features

Remove predictor features with zero variance.

Prune features with NaNs

Remove a feature column when the pruning rule detects missing (NaN) values in that feature. For example, a predictor [1, NaN, 3] is at risk of removal, whereas [1, 2, 3] has no NaN and passes this criterion. Pruning uses training-fold information and changes the set of predictors seen by the learner.

Prune features with Infs

Remove a predictor column containing infinite values (Inf or -Inf) under the selected pruning rule. For example, [1, Inf, 4] fails this criterion; [1, 2, 4] does not. Infinity can arise from division by zero or an upstream transformation and should not be interpreted as a legitimate large measurement.

Single-value cutoff percent

Remove features dominated by one repeated value when its prevalence reaches the specified percentage. With a cutoff of 95%, a column containing 95 zeros and 5 nonzero values among 100 cases is a candidate for removal. Empty disables this extra filter. Such pruning removes near-constant predictors but may also discard rare-event indicators.

Skewness correction

Transform skewed feature distributions. Logarithmic, Box–Cox and Yeo–Johnson transformations differ in their supported input ranges and how they reshape the tails of the distribution.

Transform

Choose how strongly asymmetric feature distributions are transformed. log compresses large positive values and requires suitable positive inputs; Box–Cox is a family of power transforms that generally requires strictly positive values; Yeo–Johnson accommodates zero and negative values as well. These methods change the interpretation and units of predictors and should be fitted on training data.

Absolute skewness threshold

Skewness describes asymmetry: zero is approximately symmetric, large positive values indicate a long upper tail and large negative values a long lower tail. The absolute threshold decides which features are transformed. For example, threshold 1 targets features with |skewness| greater than 1 while leaving more symmetric columns unchanged.

Box-Cox lambda mode

In automatic mode, the Box–Cox power parameter lambda is fitted from training data; manual mode uses the value(s) entered below. Lambda near 1 approximates an unchanged scale and lambda near 0 approaches a logarithm for positive values. A fixed lambda is useful for an explicitly defined transformation rather than a data-adaptive one.

Manual Box-Cox lambda

Box–Cox lambda controls the power applied to strictly positive values: lambda 1 is approximately linear and lambda 0 gives the log limit. Enter one value to fix it or multiple values as optimization candidates where supported. Box–Cox is not directly defined for zero or negative data without a separately justified shift.

Yeo-Johnson lambda mode

Yeo–Johnson extends power transformations to zero and negative predictor values, unlike ordinary Box–Cox. Automatic mode estimates its lambda from the training partition; manual mode uses the supplied lambda. The choice controls how strongly long positive or negative tails are compressed.

Manual Yeo-Johnson lambda

Manual Yeo–Johnson lambda determines the transformation shape for both positive and negative feature values. Lambda 1 leaves values close to unchanged; alternative values can reduce skew. Multiple entries represent candidate settings when optimization is available; interpret results on the transformed scale.

Copy features

Store a copy of the current predictor representation for subsequent operations. Copying preserves a reference to the earlier feature space without itself fitting a statistical model.

Copy label

Attach a name to a copy of the current feature representation so it can be recognized when the pipeline uses stored or combined representations later. For example, retaining a copy of the original regional variables before a transformation can help distinguish those variables from a subsequently reduced feature set. The name does not change feature values.

Feature ranking / weighting

Ranking estimates the relevance of each input feature but does not by itself delete features. The immediately following feature-ranking action decides whether to weight variables continuously or retain a subset. Correlation, AUC, F-score and ANOVA provide comparatively simple univariate criteria; Relief and IMRelief compare neighbouring cases; FEAST measures information and redundancy; GFLIP, Simba, RGS and linear-model ranking use more involved optimization. Most methods use outcome labels, so fitting belongs inside the training partition. External weights are an exception because their source is supplied explicitly.

Ranking algorithm

Choose what constitutes a useful predictor. pearson/spearman measure linear/monotonic association with a target; auc assesses class separation; fscore/anova compare groups; varfeat ranks by feature variance without necessarily measuring prediction relevance. relief, imrelief and idetect use neighbourhood-based relevance; simba, gflip and rgs optimize feature weights; feast uses mutual-information criteria to balance information and redundancy. pls ranks through a response-associated projection; libsvm/liblin use linear support-vector model coefficients; extern/extern2 import previously computed weights. Choose a criterion compatible with classification versus regression and review its nested options; a ranking score is not a held-out performance estimate.

Use ranking to

upweight gives higher relevance scores greater influence when the subsequent ranking action uses feature weights; downweight reverses the weighting preference. This changes which measured patterns the learner emphasizes and can reverse the intended order if applied accidentally. Inspect the direction and sign of the ranking scores before combining this option with absolute-weight postprocessing or hard feature selection.

Ranking target source

Normally calculate feature relevance against the analysis target (NM target). Choose workspace when the ranking should instead explain a different, aligned outcome, such as age rather than diagnosis; legacy preserves a previously imported source. The selected target must have one entry per subject and should not contain information unavailable in the relevant training fold.

Workspace label variable

Select a MATLAB workspace vector with one target value for each subject in the active NM case order. For 200 subjects, the variable must contain 200 aligned entries. A categorical vector can support group-discrimination ranking, whereas a continuous vector supports association/regression ranking. An incorrect row order silently changes the scientific meaning of the scores.

Task induced by custom target

auto infers whether a custom ranking target should be treated as categorical classification or continuous regression. Override only when a numeric coding is ambiguous: group labels 1, 2 and 3 represent three categories, not a quantitative 1-to-3 response, while continuous symptom scores may be a regression target even if integer-valued. This choice affects which ranking statistics are meaningful.

Auto-detected target type

Read-only task type inferred from the selected workspace ranking target.

External ranking source

Reuse feature importance weights instead of estimating them in this training fold. Sources include a workspace vector/matrix, an image mapped into the active feature mask, an existing NM weighting map or an imported legacy definition. For example, an anatomical prior may assign higher weights to selected cortical regions. Verify feature identity and provenance: externally derived labels or weights must not originate from the held-out evaluation data.

External ranking workspace variable

Provide numerical weights aligned to the current feature axis. If the modality has 100 features, supply a vector of 100 values, or a matrix whose second dimension is 100 when multiple weight sets are expected. Column 10 must refer to the tenth active feature, not an arbitrary original file column; mismatched feature order makes an otherwise valid vector scientifically wrong.

External NIfTI/GIfTI/surface ranking file

Select a NIfTI volume, GIfTI surface file or supported surface image containing feature weights. The module vectorizes the file in the active NM mask/geometry before applying the ranking. A weight image in another spatial grid, mesh or mask may not correspond to the analysis features; verify alignment and resampling explicitly rather than assuming filenames imply compatibility.

Dataset weighting image index

Select an existing weighting map from the active NeuroMiner dataset by its index. This reuses the map without recalculating importance, for example an already imported brain atlas weighting image. Confirm that the chosen index refers to the intended source and matches the current modality feature ordering.

Postprocess: absolute weights

Replace signed ranking weights with their magnitudes before the ranking action. For example, -0.8 and +0.8 then have equal importance: direction of association is lost. Useful for selecting strongly associated features regardless of sign, but inappropriate when positive and negative effects must remain distinguishable.

Postprocess: scale weights to [0,1]

Rescale ranking weights to the unit interval during postprocessing.

Postprocess: replace zeros/NaNs with realmin

MATLAB realmin is the smallest positive normalized double-precision value (approximately 2.2 × 10^-308), not the smallest observed rank. Replacing zero or undefined (NaN) weights with this tiny positive number can keep downstream operations numerically defined, but also turns a genuinely absent/undefined weight into a nonzero one. Enable only when the subsequent ranking action specifically requires positive finite weights; do not treat it as a remedy for invalid input data.

Postprocess: replace Infs with max

Replace infinite feature weights with the largest finite weight in the ranking vector. This avoids infinite arithmetic downstream but makes formerly unbounded scores tie with the largest finite score. Investigate why infinite weights occurred, for example division by negligible variance, before using this numerical workaround.

Algorithm-specific parameters

Open the controls for the selected ranking algorithm rather than a universal settings page. Examples include neighbour count for Relief, class weighting and bootstrap iterations for F-score, utility and stopping conditions for GFLIP/Simba, information criterion and binning for FEAST, or PLS response and sparsity. Only settings relevant to the chosen method affect the fitted ranking.

F-score computation method

Algorithm: fscore

F-score ranks features by how far group centers are separated relative to variation within groups. mean uses means and standard deviations; median uses medians and interquartile ranges, reducing the influence of extreme observations. For example, a single extreme value can inflate within-group SD and lower a mean-based score even when typical group values differ. This is a feature-ranking statistic, not model accuracy.

Class-imbalance weighting mode

Algorithm: fscore

When outcome classes are imbalanced, the majority class can dominate aggregate ranking estimates. none uses the unweighted procedure; auto lets the configured F-score method calculate class-related weights; manual uses an explicitly supplied sample-weight vector. Select manual only when the weight definition and case alignment are justified; weights affect which subjects contribute most strongly to feature scores.

Manual sample-weight vector

Algorithm: fscore

Supply a numerical workspace vector with one nonnegative weight per subject, aligned to the active case order. A value of 2 gives an observation greater influence than a value of 1 in the weighted F-score calculation. Use this only with manual weighting and verify that the weighting scheme does not encode held-out outcomes.

Bootstrap iterations

Algorithm: fscore

Number of F-score bootstrap iterations; zero disables bootstrapping.

Number(s) of nearest neighbours

Algorithm: relief

Relief compares a case with nearby cases to identify features that distinguish outcomes in local neighbourhoods. k sets how many neighbours contribute; for example, k=5 averages evidence from five nearby cases rather than a single possibly atypical neighbour. A larger k smooths local differences and costs more computation; multiple values are candidate settings.

# starting points

Algorithm: gflip

Number of independent starting points for ranking optimization.

Maximum # of iterations

Algorithm: gflip

Maximum number of ranking-optimization iterations.

Block size

Algorithm: gflip

GFLIP updates weights or selected features in blocks. A block size of 1 changes one feature at a time; larger blocks consider more features jointly per update. This can alter the search trajectory and computing effort; it is not the number of output features to retain.

Utility function

Algorithm: gflip

Choose the objective GFLIP optimizes while searching for feature weights. zero-one rewards correct versus incorrect class decisions without grading their margins; linear evaluates a continuously varying decision score; sigmoid converts the score through a smooth S-shaped response controlled by beta. These objectives can rank the same features differently. Sigmoid additionally exposes beta settings.

Sigmoid beta mode

Algorithm: gflip

Beta controls the slope of the sigmoid utility used in GFLIP. auto derives the slope according to the implemented optimizer; manual uses the specified beta candidate(s). A steeper sigmoid concentrates sensitivity near its transition region, whereas a shallower one rewards a wider range of scores.

Sigmoid beta value(s)

Algorithm: gflip

Provide positive beta candidate values for the sigmoid utility when manual mode is selected. Larger values generally produce a sharper transition of utility around the decision score. Multiple values can be optimized; beta is not a feature count or class weight.

Multi-group processing

Algorithm: gflip

auto uses the algorithm's task-dependent group choice. multi-group evaluates group differences jointly when more than two classes exist; pairwise operates on class comparisons separately. This setting controls GFLIP's ranking formulation and must be interpreted alongside the preprocessing-wide binary/multi-group mode; it does not rename or recode the original outcome labels.

GPU flag

Algorithm: gflip

Enable GPU execution for the selected ranking algorithm.

# starting points

Algorithm: simba

Number of independent starting points for ranking optimization.

Maximum # of iterations

Algorithm: simba

Maximum number of ranking-optimization iterations.

Feature-stability stopping criterion [%]

Algorithm: simba

Simba may stop once feature rankings become sufficiently stable across iterations. This percentage sets the algorithm's stability stopping criterion: a stricter convergence requirement generally allows more iterations, whereas a more permissive criterion stops earlier. The value is a stopping condition, not an estimate of predictive accuracy.

Block size

Algorithm: simba

Simba changes the candidate feature-weight solution in blocks; a block size of 1 updates one feature at a time, whereas larger values change several jointly. This affects optimization granularity and runtime, not the final number of features retained by the following ranking action.

Utility function

Algorithm: simba

Simba offers linear and sigmoid utilities. linear values changes in its decision score continuously; sigmoid maps the score through a bounded S-shaped function, whose steepness is controlled by beta. Different utilities change the feature-ranking optimization objective, not the class labels themselves.

Sigmoid beta mode

Algorithm: simba

For Simba's sigmoid utility, auto chooses beta according to the optimizer; manual uses entered candidate values. Beta controls the steepness of the score-to-utility mapping, so it changes how strongly near-boundary differences influence feature ranking.

Sigmoid beta value(s)

Algorithm: simba

Specify candidate beta values when Simba's sigmoid utility uses manual beta. A larger beta gives a sharper transition around the utility's midpoint; a smaller value responds more gradually. This is a hyperparameter of ranking optimization, not the classifier's regularization parameter.

Feature-ranking action

Apply the relevance weights calculated by the immediately preceding ranking step. soft weighting keeps the feature columns but changes their influence; hard extraction removes columns according to a percentile, absolute score, top-k count or comparison cutoff. For example, ranking 500 features and retaining the top 50 reduces the model input from 500 to 50 predictors. Selection rules and candidate thresholds are estimated in training folds, not chosen from held-out test performance.

Ranking action

soft_weight retains features and weights their values; percentile_threshold keeps features passing a rank percentile; absolute_threshold keeps those passing a numeric score; top_features retains the best k; operator_cutoff applies a chosen comparison such as weight >= 0.5. The last four are hard selection: they change feature count. Choose the action according to whether you want continuous weighting or a smaller input matrix.

Soft-weighting exponent(s)

For soft weighting, the exponent changes the contrast between large and small feature weights. For nonnegative weights, an exponent of 1 retains the weight scale, 2 makes strong weights relatively more dominant, and a value below 1 reduces contrast. Candidate exponents can be optimized. Check sign handling when the ranking produces negative values.

Percentile threshold(s)

Cut off the ranking by percentile rather than a fixed score. For example, the 75th percentile retains weights in the top quarter of the observed score distribution when the comparison is oriented toward larger weights. Multiple values (such as 25, 50 and 75) are alternative selection strengths, not percentages of explained variance.

Absolute threshold(s)

Retain features whose ranking score passes the specified numeric threshold, for example weights above 0.5. Unlike percentiles, the number retained depends on the weight scale and distribution; a threshold suitable for correlations may be meaningless for F-scores. Multiple values are selection candidates.

Top feature count(s)

Keep the k highest-ranked features: for example, 20 retains twenty predictors regardless of how large their relevance scores are. Supply multiple counts to optimize feature-set size within training. The value is a feature count, not a percentile, and cannot exceed the available feature dimension.

Operator

Select the comparison applied to ranking weights in operator/cutoff extraction: >= and > retain sufficiently large values; <= and < retain sufficiently small values; ~= retains values different from the cutoff. For example, >= 0.3 keeps scores of 0.3 or higher. Verify the direction of relevance before choosing an operator.

Operator cutoff(s)

Numeric score(s) compared with the selected operator. With operator >= and cutoff 0.5, features scoring at least 0.5 are retained; with <= 0.5 the complementary direction is selected. Multiple cutoffs are candidate extraction strengths, and their meaning depends on the scoring algorithm.

Clusterize suprathreshold imaging features

When hard selection is applied to imaging features, optionally group spatially adjacent suprathreshold voxels/vertices into clusters rather than treating every surviving location independently. This requires a valid imaging geometry and is unavailable for soft weighting. Cluster definitions depend on the selected score threshold and adjacency representation.

Dimensionality reduction

Dimensionality reduction fits a mapping from the original features to a smaller representation using training-fold data. PCA summarizes covariance directions, NMF yields additive nonnegative factors, ICA seeks independent sources, PLS relates components to a response, and manifold methods seek local structure. The resulting components are derived features, not necessarily individual brain regions. To optimize component count efficiently, first fit a sufficiently large projection and let the next Extract dimensions step compare retained subsets.

Dimensionality-reduction method

Choose a projection with assumptions suitable for the data. Linear unsupervised methods: PCA (principal component analysis, maximum variance); RobPCA (robust PCA, outlier resistance); SparsePCA (sparser loadings); ProbPCA (probabilistic PCA); FactorAnalysis (latent covariance factors). Nonnegative additive models: NNMF (nonnegative matrix factorization), NeNMF (Nesterov-accelerated NMF) and optNMF (orthogonal projective NMF; legacy-listed without its own option branch); nonnegative inputs/representation are important. Supervised methods: PLS (partial least squares, response-associated components), LDA (linear discriminant analysis), GDA (general discriminant analysis), NCA (neighbourhood component analysis) and LMNN (large-margin nearest-neighbour metric learning). Independent components: fastICA (independent component analysis). Local/manifold methods: LPP (locality-preserving projections), LLTSA (linear local tangent space alignment), Laplacian (Laplacian eigenmaps) and LLE (locally linear embedding). Choose PCA for a transparent variance-based baseline; supervised methods require careful training-fold label isolation. Not every listed legacy method has the same runtime support or out-of-sample mapping behavior; inspect the chosen method's status and parameters.

Fitted projection dimensionality

Set how large a projection the module fits. In absolute mode 20 means twenty components; in PCA energy mode 0.8 requests components accounting for approximately 80% of fitted variance. When a subsequent Extract dimensions step tests 5, 10 and 20, fit at least 20 components here rather than refitting a separate projection for each option. Meaning depends on the dimensionality mode and selected method.

Fitted dimensionality mode

Choose a fixed number of components, a percentage of available components, or an explained-energy target. Percentage and energy modes are available for PCA-based methods.

Use Procrustes template alignment

Procrustes alignment rotates or reflects comparable fitted component spaces toward a common reference template, reducing arbitrary orientation/sign differences across cross-validation fits. This is useful when subsequent procedures compare corresponding PCA-derived components across folds. It does not make unstable components biologically equivalent, and the template estimation population must respect evaluation boundaries.

Use all training data for template generation

WARNING: This option builds the alignment/projection template from the complete available training set rather than independently within each evaluation training partition. The NM 1.4 manual explicitly cautions that using all available data for template generation can leak information across internal cross-validation and make performance estimates optimistic; such estimates should not be presented as unbiased generalization evidence. Keep this off when reporting CV performance. If enabled for alignment or exploratory work, obtain an independent external-cohort evaluation before making generalization claims.

Correct nuisance / batch effects

Nuisance correction seeks to reduce systematic variation unrelated to the scientific target. partial regression removes estimated linear covariate effects (for example, motion); ComBat/CovBat harmonizes site- or scanner-associated distributions (and optionally covariance); Disparate Impact Removal (DIR) adjusts disparities across specified categorical groups. These methods make different assumptions and can remove clinically meaningful variation if site, diagnosis and other covariates are confounded. Fit parameters within training folds and inspect which biological effects are explicitly retained.

Nuisance-correction method

partial fits a regression of predictors on selected covariates and subtracts or adds estimated effects; it is appropriate for approximately linear nuisance associations. combat performs ComBat/CovBat batch harmonization, adjusting group-dependent means/variances and optionally covariance patterns. dir (Disparate Impact Removal) aims to align feature distributions across selected categorical groups. None of these methods guarantees removal of all confounding or preservation of target information; choose based on the acquisition design and the scientific hypothesis.

Method-specific parameters

Open the nested page for partial correlation, ComBat/CovBat, or Disparate Impact Removal settings.

Optionally restrict correction to selected predictor features. For example, an imaging mask can identify which regional variables are adjusted while others pass through unchanged. Check that the mask/index refers to the active feature axis after earlier preprocessing; otherwise the intended variables may be missed or incorrectly corrected.

Algorithm: combat

ComBat variant

Algorithm: combat

combat harmonizes batch-related differences in feature means and variances. covbat extends harmonization to differences in covariance patterns between features using a principal-component representation. CovBat can address scanner-dependent correlation structure but may change multivariate relationships of biological interest. Choose it only when covariance harmonization is scientifically warranted and the available per-batch samples support estimation.

CovBat K

Algorithm: combat

For CovBat, K specifies how many principal components are used when harmonizing covariance patterns. A smaller K focuses on leading covariance directions, while a larger K adjusts more of the multivariate structure. Leave empty to determine K from the cumulative-variance setting instead.

CovBat cumulative variance

Algorithm: combat

If CovBat K is empty, retain enough principal components to reach this fraction of cumulative variance; for example, 0.95 targets approximately 95% of the fitted variance. A higher threshold includes more covariance directions and may increase the scope of adjustment. This is not a target model accuracy threshold.

Offset correction

Estimate and remove group-specific offsets relative to a reference mean. Group definitions determine which observations contribute to each offset estimate.

Source grouping covariate

Select the NM covariate whose categories define groups for estimating group-specific and overall predictor means. For example, source codes 1 and 2 might represent two scanners. Cases coded 0 are excluded from this calculation. The estimates determine which group offsets are corrected downstream.

Destination grouping covariate

Select the grouping covariate used to assign the learned mean-offset adjustment to recipient cases. It may be the same as the source grouping or a distinct but compatible coding. Cases coded 0 are skipped. Mismatched group labels can apply the wrong correction, so verify their mapping before use.

Deviation mapping

Deviation mapping fits a normative relationship between a covariate/design matrix (for example, age and sex) and predictor features, then represents each individual's departure from the expected feature pattern. PLS or sparse PLS provides the normative reconstruction. A deviation describes difference from the fitted reference, not automatically disease abnormality; interpretation depends on the reference population, covariate coverage and training-fold fitting.

Normative algorithm

pls (partial least squares) finds latent predictors that reconstruct feature patterns associated with the normative design. spls (sparse PLS) additionally constrains feature and covariate loadings, allowing a more selective model. Both depend on the chosen reference cases; sparse constraints can improve interpretability but remove important normative structure.

Covariate/design matrix source

Choose what defines expected normative variation. workspace supplies a user-selected design matrix, nm_covars uses selected NM covariate columns, and legacy retains an imported design. For example, using age as a predictor asks how feature values depart from their age-expected profile; using diagnosis labels would answer a different and usually inappropriate normative question.

Workspace covariate/design matrix

Provide a numeric reference/design matrix with one row per NM subject and columns representing normative predictors (such as age, sex or scanner-adjusted factors). A 100-subject analysis needs 100 correctly aligned rows. Do not use outcome diagnosis labels as the normative design: that would encode the condition being assessed into the expected reference itself.

Sparse-PLS U controls how selectively predictor features contribute to the normative latent components. Graph construction

Graph construction converts measurements into a network: nodes represent regions or features and edges represent their pairwise relationship. The supported options are KL-divergence graphs from regional imaging distributions and a normative-network approach comparing individuals with a reference group. Graph edges are derived features, not necessarily physical anatomical connections. This module changes the feature representation; subsequent sparsity thresholding and graph metrics depend on how edges were defined.

Graph construction method

KL divergence compares regional distributions in an image and derives symmetric distribution-difference edges; this requires an appropriate parcellation and is available for subject-specific spatial extraction. Normative network + 1 constructs an individual network relative to a calibration/reference group and is fitted in the CV-bound stage. The two outputs have different scientific meanings: distribution difference between regions versus deviation from reference network relationships.

Similarity measure

For Normative network + 1, choose how two regional signals are compared. Mutual information captures statistical dependence beyond a strictly linear relation; Pearson measures linear association; Spearman's rho and Kendall's tau measure rank-based monotonic relationships. For example, a curved monotonic relationship may have strong Spearman correlation but a weaker Pearson correlation. Different similarity definitions produce different edge weights.

Reference group source

Define the population underlying the normative reference network: calibration uses available calibration cases; file reads a supplied group definition; workspace uses a named/expression-based group; legacy preserves the imported reference. An individual's network can differ substantially depending on reference age, site or diagnostic mix. Confirm the group is independent of held-out cases where required.

Reference group file

Choose a text, CSV or MAT file specifying the reference group for normative network construction. It must identify the intended cases in the appropriate NM case order; for example, a control group is only a valid reference if its case membership is correctly aligned. This option is used when Reference group source is file.

Reference group workspace variable/expression

Specify the MATLAB workspace variable or expression defining reference-group membership for normative graph construction. The selected cases must align to the current analysis and be scientifically suitable as a reference. For example, an indicator of control subjects should not accidentally include held-out evaluation cases.

Parcellation atlas

Choose the atlas dividing image-space features into labelled brain regions. The KL-divergence graph compares regional value distributions defined by that parcellation; changing the atlas changes both nodes and edge interpretation. Atlas geometry must correspond to the image's anatomical space and mask.

Brain mask

Read-only summary of the brain mask available to image-space KL-divergence construction.

Graph sparsity thresholding

Retain a specified fraction of network edges according to the selected thresholding rule. Sparsity changes graph density and therefore the topology seen by downstream graph metrics.

Edge-retention fraction(s)

Retain a specified fraction of graph edges, such as 0.10 for the strongest 10% or 0.20 for 20%, according to the inherited edge-selection rule. Smaller fractions produce sparser networks and may remove weak but real connections; larger ones retain more potentially noisy edges. Multiple fractions are candidate sparsity levels and should not be confused with percentages of explained variance.

Graph metrics

Summarize a graph into numerical network features after its edges have been constructed and optionally thresholded. Degree counts connections, strength summarizes edge weights, clustering measures local triangles, centrality describes influential nodes and efficiency relates to path lengths. These measures depend strongly on graph construction, edge sign/weight conventions and sparsity; they are not interchangeable biological biomarkers.

Global options

Global preprocessing controls concern how classification groups or regression targets are handled, not the order of predictor transformations. In a multiclass analysis, the group-processing setting controls whether fitting uses binary comparisons or a joint multi-group representation. For regression, target scaling and power transformation change the numbers presented to the learner and the units in which predictions are expressed.

Multiclass group-processing mode

For one-vs-all multiclass decomposition, NM2 requires joint multi-group preprocessing and displays this setting as read-only. This is a constraint arising from the selected analysis decomposition, not a new label encoding or evidence that only two classes exist.

Multiclass group-processing mode

For a classification target with more than two classes, binary mode processes classes through the analysis' binary comparison decomposition; multi-group mode estimates preprocessing from the groups jointly. For example, three diagnostic groups can be handled as pairwise comparisons or with a common group-level preprocessing model. This setting controls preprocessing estimation, not the number of original labels or the learner's multiclass method. One-vs-all decomposition may require multi-group mode.

Scale target values

Enable scaling of continuous regression outcome values as part of target preprocessing. For example, a symptom sum score and a biomarker concentration have different raw units and ranges; scaling changes the numerical values presented to a regression learner. Interpret prediction errors and any inverse transformation on the appropriate original or transformed target scale. This setting does not apply to categorical diagnosis labels.

Apply power transformation to target

Apply a power transformation to a regression outcome: the legacy backend computes transformed_label = original_label^p, not exp(original_label). For example, an outcome of 3 becomes 9 when p=2; p=1 leaves the value unchanged. Fractional powers of negative outcomes may be undefined in real arithmetic. The transformed outcome has different units, so predictions and errors need scale-aware interpretation.

Target exponent

Exponent p for the regression power transform y^p. p=1 leaves values unchanged, p=2 squares them, and p=0.5 takes square roots where defined. This is not an exponential exp(y) transform. Choose p with regard to negative/zero values and the intended interpretation of reconstructed predictions.
